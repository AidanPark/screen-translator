วิธีใช้ Screen Translate

แปลข้อความบนหน้าจอแบบเรียลไทม์ — เกม แชท การ์ตูน แอปต่างๆ

🚀 เริ่มต้นอย่างรวดเร็ว

1
ให้สิทธิ์ 2 อย่าง เมื่อเปิดครั้งแรก แอปจะขอสิทธิ์ แสดงทับแอปอื่น (สำหรับฟองลอย) และ บันทึกหน้าจอ (เพื่ออ่านข้อความบนจอ) บน Android 14 ขึ้นไป ให้เลือก “ทั้งหน้าจอ” เมื่อระบบถาม
2
ดูโฆษณาสั้น 1 ครั้ง โฆษณาแบบมีรางวัลเพียงครั้งเดียวทำให้แอป ไร้โฆษณาจนกว่าคุณจะปิดแอป ถ้าข้ามโฆษณา หน้าโฆษณาจะเปิดขึ้นอีกครั้งในการแปลครั้งถัดไป
3
ลากตัวชี้ไปที่ข้อความ ฟองลอยจะปรากฏบนหน้าจอ ลากมัน — ตัวชี้จะตามนิ้วคุณ ชี้ที่ข้อความใดก็ได้แล้วปล่อย: คำแปลจะเด้งขึ้นตรงนั้นทันที

📌 แถบเมนูลอย

แถบเมนูลอยอยู่บนหน้าจอตลอดเวลา — ศูนย์ควบคุมของแอป จะซ่อนชั่วคราวเฉพาะตอนจับภาพ (ขณะกดตัวชี้ค้าง) และตอนที่หน้าต่างคำแปลแสดงอยู่เท่านั้น ทำได้มากกว่าที่คิด:

  • ไอคอนโหมดตรวจจับ (ซ้าย) — สลับระหว่าง คำ / ประโยค / ย่อหน้า / เลือกพื้นที่ / พื้นที่คงที่
  • ภาษาต้นทาง — Auto ตรวจจับให้อัตโนมัติ แตะเพื่อปักหมุดเป็นภาษาใดภาษาหนึ่งก็ได้
  • ⇄ สลับ — สลับภาษาต้นทางกับปลายทางในแตะเดียว
  • ภาษาปลายทาง — แตะเพื่อเลือกจากกว่า 110 ภาษา
  • ไอคอนเอนจิน (ขวา) — แตะเพื่อสลับเอนจินการแปล: Google, DeepL, GPT, Gemini, Claude

ตัวแถบเมนูลากไปวางตรงไหนก็ได้ ถ้าคุณแทบไม่เปลี่ยนตัวเลือกเหล่านี้และรู้สึกเกะกะ ปรับความโปร่งใสและเลย์เอาต์ได้ในการตั้งค่า — หรือปิดแสดงแถบเมนูเพื่อซ่อนไปเลย

🎯 โหมดการแปล 5 แบบ

สลับโหมดด้วยไอคอนโหมดตรวจจับบนแถบเมนูลอย

คำ

ชี้ที่คำเดียวเพื่อแปลเฉพาะคำนั้น เหมาะกับการเรียนภาษา — แตะเพื่อฟังการออกเสียง (TTS) ได้ด้วย

ประโยค

ชี้ที่ตรงไหนก็ได้ในประโยคเพื่อแปลทั้งประโยค โหมดยอดนิยมสำหรับแชทและโซเชียลมีเดีย

ย่อหน้า

ชี้ที่บล็อกข้อความเพื่อแปลทั้งย่อหน้าในครั้งเดียว — เหมาะกับบทความและเอกสาร

เลือกพื้นที่

ลากวาดกรอบรอบส่วนที่ต้องการแปลพอดี เหมาะมากเมื่อเลย์เอาต์ซับซ้อน

พื้นที่คงที่ สำหรับเกมและซับไตเติล

ปักหมุดพื้นที่หนึ่งบนหน้าจอ — แอปจะแปลใหม่อัตโนมัติทุกครั้งที่เนื้อหาเปลี่ยน สร้างมาเพื่อบทสนทนาในเกมและซับไตเติลวิดีโอ

🌐 ภาษา

รองรับกว่า 110 ภาษา ภาษาต้นทางตรวจจับอัตโนมัติ เพียงเลือกภาษาปลายทางจากแถบเมนู สลับได้ทุกเมื่อ

🤖 การแปลด้วย AI (ไม่บังคับ)

เอนจิน Google ในตัวฟรีและไม่ต้องตั้งค่า อยากใช้การแปลด้วย AI? เชื่อมต่อคีย์ API ของคุณเอง:

  • DeepL — มีแผนฟรีที่ deepl.com
  • OpenAI (GPT) — รับคีย์จากแดชบอร์ด OpenAI
  • Gemini — ระดับฟรีผ่าน Google AI Studio
  • Claude — รับคีย์จาก Anthropic Console

แถบเมนู → เอนจินการแปล → เลือกเอนจิน → วางคีย์ ค่าใช้จ่ายเรียกเก็บจากบัญชีของคุณกับผู้ให้บริการนั้น แอปไม่บวกเพิ่ม

ถ้าการแปลล้มเหลว แอปจะแสดงสาเหตุบนหน้าจอทันที — คีย์ API ไม่ถูกต้อง เครดิตหมด ถึงขีดจำกัดการใช้งาน หรือข้อผิดพลาดเครือข่าย หมายเหตุ: มีคีย์ที่ใช้ได้อย่างเดียวยังไม่พอ — บัญชีกับผู้ให้บริการต้องมีเครดิตหรือระดับฟรีที่ใช้งานได้ด้วย

🔊 อ่านออกเสียงและเสียง TTS

แอปอ่านข้อความออกเสียงได้: แตะไอคอนลำโพงบนคำแปล หรือเปิดอ่านออกเสียงอัตโนมัติในการตั้งค่า ตัวเลือกเป้าหมายการอ่านใช้เลือกว่าจะอ่านต้นฉบับหรือคำแปล

เลือกเสียงได้ที่ การตั้งค่า → เสียง TTS: เสียงจัดกลุ่มตามภาษา แตะเสียงใดก็จะเล่นตัวอย่างสั้นๆ ให้เทียบก่อนเลือก

💬 ตอบกลับในแชท

แปลข้อความแชทแล้ว? แตะไอคอนตอบกลับที่มุมขวาล่างของหน้าต่างคำแปล แล้วพิมพ์คำตอบเป็นภาษาของคุณ — ระบบจะแปลเป็นภาษาของอีกฝ่ายทันที

แตะคัดลอก วางในแชทแล้วส่งได้เลย คุยกันได้ทั้งบทสนทนาโดยไม่ต้องออกจากแอปแชท

❓ คำถามที่พบบ่อยและการแก้ปัญหา

ฟองลอยหายไป

เปิดแอปอีกครั้งเพื่อรีสตาร์ทบริการ ถ้าเกิดซ้ำ ตรวจสอบว่าสิทธิ์ แสดงทับแอปอื่น ยังเปิดอยู่ และยกเว้นแอปจากการเพิ่มประสิทธิภาพแบตเตอรี่ (การตั้งค่า → แบตเตอรี่ → ไม่จำกัด)

การแปลครั้งแรกช้าหรือขึ้นว่า “กำลังเตรียม”

การใช้ครั้งแรกจะดาวน์โหลดโมเดล OCR หนึ่งครั้งผ่านบริการ Google Play หลังจากนั้นการรู้จำจะทันทีและ OCR ทำงานออฟไลน์ได้

บางหน้าจอไม่มีอะไรเกิดขึ้น

แอปที่บล็อกการจับภาพหน้าจอ (แอปธนาคาร เครื่องเล่นวิดีโอ DRM) ไม่สามารถจับภาพได้ — Android ซ่อนเนื้อหาเหล่านั้นจากแอปจับภาพทุกตัว

ทำไมถึงเห็นโฆษณา?

โฆษณาสั้น 1 ครั้งต่อเซสชันทำให้ฟีเจอร์หลักทั้งหมดฟรี หลังดูโฆษณาแล้ว แอปจะไร้โฆษณาโดยสมบูรณ์จนกว่าคุณจะปิด

มีข้อความ ⚠ บอกว่าการแปลล้มเหลว

ข้อความจะบอกสาเหตุ คีย์ API ไม่ถูกต้อง: ตรวจคีย์ในการตั้งค่าอีกครั้ง เครดิตหมด: เติมเงินที่คอนโซลของผู้ให้บริการ — คีย์ที่ใช้ได้ก็ยังต้องมีเครดิต ถึงขีดจำกัด: รอสักครู่แล้วลองใหม่ ข้อผิดพลาดเครือข่าย: ตรวจสอบการเชื่อมต่อ

คุณภาพการแปลดูแปลกๆ

ลองโหมดประโยคหรือย่อหน้า (บริบทมากขึ้น = แปลดีขึ้น) หรือเชื่อมต่อเอนจิน AI (DeepL/GPT/Gemini/Claude) เพื่อคุณภาพที่ดีที่สุด
