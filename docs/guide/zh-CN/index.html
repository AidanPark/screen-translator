Screen Translate 使用指南

游戏、聊天、漫画、应用 — 实时翻译屏幕上的任何文字。

🚀 快速上手

1
授予两项权限。首次启动时，应用会请求显示在其他应用上层（用于悬浮气泡）和屏幕捕获（用于识别屏幕文字）。Android 14 及以上请选择“整个屏幕”。
2
观看一条短广告。看完一条激励广告后，直到关闭应用前都不会再有广告。如果跳过广告，下次翻译时广告页面会重新出现。
3
把指针拖到文字上。屏幕上会出现悬浮气泡。拖动它，指针会跟随手指。在任意文字上停住：识别文字时，指针内会有一个小圆环在转动，随后译文就在原处弹出。松开手指后，译文会在屏幕上停留几秒。

📌 悬浮菜单栏

菜单栏始终悬浮在屏幕上，是应用的控制中心。只有在按住指针进行捕获时和译文窗口显示期间才会暂时隐藏。功能比想象中多：

  • 识别模式图标（左侧）— 在单词／句子／段落／框选区域／固定区域之间切换。
  • 源语言 — Auto 自动检测；点按也可固定为某种语言。暂时无法识别屏幕文字的语言会显示为灰色。
  • ⇄ 互换 — 一键对调源语言和目标语言。
  • 目标语言 — 点按后从 110 多种语言中选择。
  • 引擎图标（右侧）— 每点一次切换一个翻译引擎：Google、DeepL、GPT、Gemini、Claude。

菜单栏可拖到屏幕任意位置。如果你很少改这些选项、觉得它碍事，可在设置中调节透明度和布局，或关闭显示菜单栏将其完全隐藏。

🎯 五种翻译模式

通过悬浮菜单栏上的识别模式图标切换模式。

单词

指向一个单词，只翻译这个词。非常适合语言学习 — 点按还能听发音（TTS）。

句子

指向句子中任意位置，翻译整句。聊天和社交媒体中最常用的模式。

段落

指向一段文字，一次翻译整个段落 — 适合文章和文档。

框选区域

拖动画框，精确圈出想翻译的内容。版面复杂时特别好用。

固定区域 适合游戏和字幕

固定屏幕上的一块区域，内容一变就自动重新翻译。专为游戏对话和视频字幕设计。

🌐 支持语言

支持 110 多种语言。源语言自动检测，只需在菜单栏选择目标语言，随时可以切换。

屏幕文字直接在手机上识别。支持的文字：拉丁字母（英语、西班牙语、法语、越南语等）、中文、日语、韩语、天城文（印地语、马拉地语、尼泊尔语等），以及 2.8 版新增的阿拉伯字母（阿拉伯语、波斯语、乌尔都语等）、俄语、乌克兰语、白俄罗斯语、保加利亚语和泰语。使用其他文字的语言，如希腊语、希伯来语或泰米尔语，仍可选作目标语言，但暂时还无法从屏幕上识别。

🤖 AI 翻译（可选）

内置的 Google 引擎免费且无需设置。想用 AI 翻译？连接你自己的 API 密钥：

  • DeepL — deepl.com 提供免费套餐
  • OpenAI (GPT) — 在 OpenAI 控制台获取密钥
  • Gemini — 通过 Google AI Studio 获取免费额度
  • Claude — 在 Anthropic Console 获取密钥

菜单栏 → 翻译引擎 → 选择引擎 → 粘贴密钥。用量计入你在该服务商的个人账户，应用不加价。

OpenAI、Gemini 和 Claude 的密钥页面（设置 → API Key）还有更多选项。可以选择模型；上下文会一并发送周围的文字（邻近句子或整个屏幕），让代词和有歧义的词翻译得更准确；翻译风格决定贴近原文的程度（直译、自然或意译）；领域则针对游戏、漫画、技术或商务文本调整措辞。

翻译失败时，原因会直接显示在屏幕上 — API 密钥无效、余额不足、达到用量上限或网络错误。注意：仅有有效密钥还不够，服务商账户还需要有余额或可用的免费额度。

🔊 朗读 & TTS 语音

应用可以朗读文字：点按译文上的扬声器图标，或在设置中开启自动朗读。通过朗读对象设置选择朗读原文还是译文。

在设置 → TTS 语音中挑选语音：语音按语言分组，点按即可播放短预览，方便比较后再选择。

💬 在聊天中回复

翻译了聊天消息后，点按译文窗口右下角的回复图标，用你自己的语言输入回复，即刻翻译成对方的语言。

点按复制，粘贴到聊天里发送即可。无需离开聊天应用，就能完整地进行对话。

❓ 常见问题与故障排除

悬浮气泡不见了

重新打开应用即可重启服务。如果频繁发生，请确认显示在其他应用上层权限仍然开启，并把应用从电池优化中排除（设置 → 电池 → 不受限制）。

第一次翻译很慢或显示“准备中”

识别模型只需下载一次。主 OCR 模型在首次使用时通过 Google Play 服务下载；阿拉伯字母、西里尔字母和泰文的模型会在安装或更新应用后立即下载，下载完成前无法识别这些语言。之后，识别可离线进行。

源语言设为 Auto 时翻译较慢

源语言为 Auto 时，应用会先判断哪种文字识别模型适合当前屏幕，因此会多花一点时间，阿拉伯字母、西里尔字母和泰文尤其如此。如果你主要阅读一种语言，在菜单栏中把它设为源语言，速度会更快。

某些屏幕上没有任何反应

禁止截屏的应用（银行应用、DRM 视频播放器）无法被捕获 — Android 会对所有捕获类应用隐藏其内容。

为什么会看到广告？

每次会话只需看一条短广告，就能免费使用全部核心功能。看完广告后，直到关闭应用前完全无广告。

出现 ⚠ 提示说翻译失败

提示会告诉你原因。API 密钥无效：在设置中重新检查密钥。余额不足：到服务商控制台充值 — 密钥有效也仍需余额。用量上限：稍等片刻再试。网络错误：检查网络连接。

翻译质量不太对

试试句子或段落模式（上下文越多，翻译越好），或连接 AI 引擎（DeepL/GPT/Gemini/Claude）获得最佳质量。

如何再次查看屏幕提示？

打开设置，点按使用方法。除了打开本指南，它还会重置提示，让提示在你使用应用时再次出现。
