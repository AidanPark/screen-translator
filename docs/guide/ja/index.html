Screen Translate の使い方

ゲーム、チャット、マンガ、アプリ — 画面上のあらゆるテキストをリアルタイムで翻訳。

🚀 クイックスタート

1
2つの権限を許可します。初回起動時に他のアプリの上に重ねて表示（フローティングバブル用）と画面キャプチャ（画面のテキスト認識用）を求められます。Android 14 以降では「画面全体」を選択してください。
2
短い広告を1本視聴します。リワード広告を1本見るだけで、アプリを閉じるまで広告なしで使えます。広告をスキップした場合は、次の翻訳時に広告画面が再び開きます。
3
ポインターをテキストにドラッグします。画面にフローティングバブルが表示されます。ドラッグすると指にポインターが追従します。テキストの上で止めておくと、文字を読み取っている間ポインターの中で小さなリングが回り、その場に翻訳が表示されます。指を離しても、翻訳は数秒間画面に残ります。

📌 フローティングメニューバー

メニューバーは常に画面に表示されている、アプリのコントロールセンターです。ハンドルを押してキャプチャしている間と翻訳ウィンドウの表示中だけ、一時的に隠れます。意外と多機能です：

  • 検出モードアイコン（左） — 単語／文／段落／範囲選択／固定エリアを切り替え。
  • 原文の言語 — Autoが自動検出。タップして特定の言語に固定もできます。画面の文字をまだ読み取れない言語はグレー表示になります。
  • ⇄ スワップ — 原文と訳文の言語をワンタップで入れ替え。
  • 翻訳先の言語 — タップして110以上の言語から選択。
  • エンジンアイコン（右） — タップするたびに翻訳エンジンが切り替わります：Google、DeepL、GPT、Gemini、Claude。

メニューバーは画面のどこへでもドラッグできます。設定をあまり変えず邪魔に感じる場合は、設定で透明度や構成を調整するか、メニューバーを表示をオフにして完全に隠せます。

🎯 5つの翻訳モード

フローティングメニューバーの検出モードアイコンでモードを切り替えます。

単語

単語を1つ指すと、その単語だけを翻訳します。語学学習に最適 — タップで発音（TTS）も聞けます。

文

文中のどこかを指すと文全体を翻訳します。チャットやSNSで最も人気のモードです。

段落

テキストのまとまりを指すと段落全体を一度に翻訳します。記事や文書に最適です。

範囲選択

翻訳したい部分をドラッグで囲みます。レイアウトが複雑なときに便利です。

固定エリア ゲーム・字幕向け

画面の一部を固定すると、内容が変わるたびに自動で再翻訳します。ゲームのセリフや動画の字幕のために作られました。

🌐 対応言語

110以上の言語に対応。原文の言語は自動検出されるので、翻訳先の言語をメニューバーで選ぶだけ。いつでも切り替えられます。

画面の文字はスマートフォン内で直接読み取ります。対応する文字は、ラテン文字（英語、スペイン語、フランス語、ベトナム語など）、中国語、日本語、韓国語、デーヴァナーガリー文字（ヒンディー語、マラーティー語、ネパール語など）、そしてバージョン 2.8 で新たに対応したアラビア文字（アラビア語、ペルシア語、ウルドゥー語など）、ロシア語、ウクライナ語、ベラルーシ語、ブルガリア語、タイ語です。ギリシャ語、ヘブライ語、タミル語など、ほかの文字を使う言語も翻訳先の言語としては選べますが、画面から読み取ることはまだできません。

🤖 AI翻訳（オプション）

内蔵のGoogleエンジンは無料で設定不要です。AI翻訳を使いたい場合は、ご自身のAPIキーを接続してください：

  • DeepL — deepl.com で無料プランあり
  • OpenAI (GPT) — OpenAI ダッシュボードでキーを取得
  • Gemini — Google AI Studio で無料枠あり
  • Claude — Anthropic Console でキーを取得

メニューバー → 翻訳エンジン → エンジンを選択 → キーを貼り付け。利用料は各サービスのご自身のアカウントに請求され、アプリは手数料を取りません。

OpenAI・Gemini・Claude には、それぞれのキー画面（設定 → API Key）に追加オプションがあります。モデルを選べるほか、文脈は周囲のテキスト（周辺の文または画面全体）も一緒に送り、代名詞やあいまいな語が正しく訳されるようにします。翻訳スタイルは原文にどこまで忠実に訳すか（直訳・自然な訳・意訳）を、分野はゲーム・マンガ・技術・ビジネス向けの言い回しを設定します。

翻訳に失敗すると、その理由が画面に表示されます — APIキーが無効、クレジット不足、利用上限、ネットワークエラー。注意：キーが有効なだけでは不十分で、そのサービスのアカウントにクレジット（または有効な無料枠）が必要です。

🔊 読み上げ & TTSボイス

アプリはテキストを読み上げできます。翻訳のスピーカーアイコンをタップするか、設定で自動読み上げをオンにしてください。読み上げ対象の設定で、原文と訳文のどちらを読むか選べます。

設定 → TTSボイスで声を選びます。声は言語ごとにまとまっていて、タップすると短いプレビューが再生されるので、聞き比べて選べます。

💬 チャットで返信する

チャットのメッセージを翻訳したら、翻訳ウィンドウ右下の返信アイコンをタップ。自分の言語で返事を入力すると、相手の言語へ即座に翻訳されます。

コピーを押してチャットに貼り付けて送信するだけ。チャットアプリを離れずに会話を続けられます。

❓ FAQ & トラブルシューティング

フローティングバブルが消えた

アプリをもう一度開いてサービスを再起動してください。繰り返す場合は、他のアプリの上に重ねて表示が許可されたままか確認し、電池の最適化からアプリを除外してください（設定 → バッテリー → 制限なし）。

最初の翻訳が遅い／「準備中」と表示される

認識モデルのダウンロードは一度だけです。メインの OCR モデルは初回使用時に Google Play 開発者サービス経由で、アラビア文字・キリル文字・タイ文字用のモデルはアプリのインストールまたはアップデートの直後にダウンロードされます。それまでは、これらの言語は読み取れません。ダウンロード後は、オフラインでも認識できます。

Auto にすると翻訳に時間がかかる

原文の言語がAutoの場合、アプリはまずどの文字認識モデルが画面に合うかを確認するため、少し時間がかかります。特にアラビア文字・キリル文字・タイ文字ではその傾向があります。主に1つの言語を読むなら、メニューバーでその言語を原文の言語に指定すると速くなります。

一部の画面では何も起きない

スクリーンショットをブロックするアプリ（銀行アプリ、DRM動画プレーヤー）はキャプチャできません — Android がすべてのキャプチャアプリからその内容を隠します。

なぜ広告が表示されるの？

セッションごとに短い広告1本で、すべてのコア機能が無料で使えます。広告の後は、アプリを閉じるまで完全に広告なしです。

⚠ 翻訳に失敗したと表示される

メッセージが理由を教えてくれます。APIキーが無効：設定でキーを再確認。クレジット不足：サービスのコンソールでチャージ — キーが有効でもクレジットは別途必要です。利用上限：少し待って再試行。ネットワークエラー：接続を確認してください。

翻訳の品質がおかしい

文モードや段落モードを試してください（文脈が多いほど翻訳が良くなります）。最高品質を求めるなら、AIエンジン（DeepL/GPT/Gemini/Claude）を接続してください。

画面のヒントをもう一度見るには？

設定を開いて使い方をタップしてください。このガイドが開くと同時にヒントがリセットされ、アプリを使っていくうちに再び表示されます。
