Comment utiliser Screen Translate

Traduisez n'importe quel texte à l'écran en temps réel — jeux, chats, BD, applis.

🚀 Démarrage rapide

1
Accordez deux autorisations. Au premier lancement, l'appli demande Superposer aux autres applis (pour la bulle flottante) et Capture d'écran (pour lire le texte à l'écran). Sur Android 14+, choisissez « Tout l'écran » quand on vous le demande.
2
Regardez une courte pub. Une seule annonce avec récompense rend l'appli sans pub jusqu'à sa fermeture. Si vous passez la pub, l'écran de pub se rouvre simplement à votre prochaine traduction.
3
Glissez le pointeur sur le texte. Une bulle flottante apparaît à l'écran. Faites-la glisser — un pointeur suit votre doigt. Maintenez-le sur un texte : un petit anneau tourne dans le pointeur pendant la lecture du texte, puis la traduction s'affiche sur place. Relâchez, et elle reste à l'écran quelques secondes.

📌 La barre de menu flottante

La barre de menu flotte en permanence à l'écran — c'est le centre de contrôle de l'appli. Elle ne se cache brièvement que pendant la capture (quand vous maintenez le pointeur) et lorsqu'une fenêtre de traduction est affichée. Elle fait plus qu'on ne le croit :

  • Icône du mode de détection (à gauche) — bascule entre Mot / Phrase / Paragraphe / Sélection de zone / Zone fixe.
  • Langue source — Auto la détecte pour vous ; touchez pour figer une langue précise. Les langues dont le texte à l'écran ne peut pas encore être lu sont grisées.
  • ⇄ Permuter — inverse source et cible d'un geste.
  • Langue cible — touchez pour choisir parmi plus de 110 langues.
  • Icône du moteur (à droite) — touchez pour changer de moteur de traduction : Google, DeepL, GPT, Gemini, Claude.

La barre se déplace où vous voulez par glisser-déposer. Si vous changez rarement ces options et qu'elle vous gêne, ajustez sa transparence et sa disposition dans les Paramètres — ou masquez-la complètement avec Afficher la barre de menu.

🎯 Cinq modes de traduction

Changez de mode avec l'icône du mode de détection sur la barre de menu flottante.

Mot

Visez un seul mot pour ne traduire que celui-ci. Idéal pour apprendre une langue — avec prononciation au toucher (TTS).

Phrase

Visez n'importe où dans une phrase pour la traduire en entier. Le mode le plus utilisé pour les chats et les réseaux sociaux.

Paragraphe

Visez un bloc de texte pour traduire tout le paragraphe d'un coup — parfait pour les articles et documents.

Sélection de zone

Tracez un cadre autour de ce que vous voulez traduire. Parfait quand la mise en page est chargée.

Zone fixe pour jeux et sous-titres

Épinglez une zone de l'écran — l'appli la retraduit automatiquement dès que son contenu change. Conçu pour les dialogues de jeux et les sous-titres vidéo.

🌐 Langues

Plus de 110 langues. La langue source est détectée automatiquement ; choisissez la langue cible dans la barre de menu. Changez à tout moment.

Le texte à l'écran est lu directement sur votre téléphone. Écritures prises en charge : alphabet latin (anglais, espagnol, français, vietnamien…), chinois, japonais, coréen, devanagari (hindi, marathi, népalais…) et — nouveauté de la version 2.8 — alphabet arabe (arabe, persan, ourdou…), russe, ukrainien, biélorusse, bulgare et thaï. Les langues utilisant d'autres écritures, comme le grec, l'hébreu ou le tamoul, peuvent toujours être choisies comme langue cible, mais ne peuvent pas encore être lues à l'écran.

🤖 Traduction IA (facultatif)

Le moteur Google intégré est gratuit et sans configuration. Vous préférez l'IA ? Connectez votre propre clé API :

  • DeepL — offre gratuite sur deepl.com
  • OpenAI (GPT) — clé depuis le tableau de bord OpenAI
  • Gemini — offre gratuite via Google AI Studio
  • Claude — clé depuis la console Anthropic

Barre de menu → moteur de traduction → choisissez un moteur → collez votre clé. L'usage est facturé sur votre compte chez ce fournisseur ; l'appli ne prend aucune commission.

OpenAI, Gemini et Claude proposent des options supplémentaires sur leur page de clé (Paramètres → API Key). Choisissez le Modèle. Contexte envoie le texte environnant (phrases voisines ou écran entier) pour que les pronoms et les mots ambigus soient bien traduits. Style de traduction règle la fidélité à l'original (littéral, naturel ou libre), et Domaine adapte la formulation aux textes de jeux, de bandes dessinées, techniques ou professionnels.

Si une traduction échoue, l'appli affiche la raison à l'écran — clé API invalide, compte sans crédit, limite d'utilisation ou erreur réseau. Attention : une clé valide ne suffit pas — le compte du fournisseur doit aussi avoir du crédit ou une offre gratuite active.

🔊 Lecture à voix haute et voix TTS

L'appli peut lire le texte à voix haute : touchez l'icône haut-parleur sur une traduction, ou activez la lecture automatique dans les Paramètres. Le réglage Cible de lecture choisit si c'est le texte original ou la traduction qui est lu.

Choisissez la voix dans Paramètres → Voix TTS : les voix sont groupées par langue, et en toucher une lance un court aperçu pour comparer avant de choisir.

💬 Répondre dans les chats

Vous avez traduit un message de chat ? Touchez l'icône de réponse en bas à droite de la fenêtre de traduction, puis tapez votre réponse dans votre langue : elle est aussitôt traduite dans la langue de votre interlocuteur.

Touchez copier, collez dans le chat et envoyez. Vous pouvez tenir toute une conversation sans quitter l'appli de messagerie.

❓ FAQ et dépannage

La bulle flottante a disparu

Rouvrez l'appli pour redémarrer le service. Si cela se reproduit, vérifiez que Superposer aux autres applis est toujours autorisé et excluez l'appli de l'optimisation de batterie (Paramètres → Batterie → Sans restriction).

La première traduction est lente ou affiche « préparation »

Les modèles de reconnaissance ne sont téléchargés qu'une fois. Le modèle OCR principal arrive via les services Google Play à la première utilisation, et les modèles pour les textes en alphabet arabe, en cyrillique et en thaï sont téléchargés juste après l'installation ou la mise à jour de l'appli — d'ici là, ces langues ne peuvent pas être lues. Ensuite, la reconnaissance fonctionne hors ligne.

La traduction est lente en mode Auto

Quand la langue source est sur Auto, l'appli vérifie d'abord quel outil de reconnaissance de texte convient à l'écran, ce qui prend un peu plus de temps — surtout pour les textes en alphabet arabe, en cyrillique et en thaï. Si vous lisez surtout une seule langue, choisissez-la comme langue source dans la barre de menu pour aller plus vite.

Rien ne se passe sur certains écrans

Les applis qui bloquent les captures (applis bancaires, lecteurs vidéo DRM) ne peuvent pas être capturées — Android cache leur contenu à toutes les applis de capture.

Pourquoi je vois une pub ?

Une courte pub par session garde toutes les fonctions principales gratuites. Après la pub, l'appli reste totalement sans pub jusqu'à sa fermeture.

Un message ⚠ dit que la traduction a échoué

Le message vous en donne la raison. Clé API invalide : revérifiez la clé dans les Paramètres. Crédit épuisé : rechargez sur la console du fournisseur — une clé valide a quand même besoin de crédit. Limite d'utilisation : patientez un instant puis réessayez. Erreur réseau : vérifiez votre connexion.

La qualité de traduction semble médiocre

Essayez le mode Phrase ou Paragraphe (plus de contexte = meilleure traduction), ou connectez un moteur IA (DeepL/GPT/Gemini/Claude) pour la meilleure qualité.

Comment revoir les astuces à l'écran ?

Ouvrez les Paramètres et touchez Mode d'emploi. En plus d'ouvrir ce guide, cela réinitialise les astuces, qui réapparaissent au fil de votre utilisation de l'appli.
