Cara Menggunakan Screen Translate

Terjemahkan teks apa pun di layar secara real-time — game, chat, komik, aplikasi.

🚀 Mulai Cepat

1
Berikan dua izin. Saat pertama dibuka, aplikasi meminta Tampil di atas aplikasi lain (untuk gelembung mengambang) dan Perekaman layar (untuk membaca teks di layar). Di Android 14+, pilih “Seluruh layar” saat diminta.
2
Tonton satu iklan singkat. Satu iklan berhadiah membuat aplikasi bebas iklan sampai Anda menutupnya. Jika iklan dilewati, layar iklan hanya akan terbuka lagi pada terjemahan berikutnya.
3
Seret penunjuk ke teks. Gelembung mengambang muncul di layar. Seret — penunjuk mengikuti jari Anda. Tahan di atas teks mana pun: cincin kecil berputar di dalam penunjuk selama teks dibaca, lalu terjemahan langsung muncul di sana. Setelah dilepas, terjemahan tetap di layar selama beberapa detik.

📌 Bilah Menu Mengambang

Bilah menu selalu mengambang di layar — pusat kendali aplikasi. Ia hanya bersembunyi sebentar saat penangkapan (selagi Anda menahan penunjuk) dan selama jendela terjemahan tampil. Fungsinya lebih banyak dari yang dikira:

  • Ikon mode deteksi (kiri) — berpindah antara Kata / Kalimat / Paragraf / Pilih Area / Area Tetap.
  • Bahasa sumber — Auto mendeteksinya untuk Anda; ketuk untuk mengunci bahasa tertentu. Bahasa yang teks layarnya belum bisa dibaca ditampilkan abu-abu.
  • ⇄ Tukar — membalik bahasa sumber dan tujuan sekali ketuk.
  • Bahasa tujuan — ketuk untuk memilih dari 110+ bahasa.
  • Ikon mesin (kanan) — ketuk untuk berganti mesin terjemahan: Google, DeepL, GPT, Gemini, Claude.

Bilahnya bisa diseret ke mana saja. Jika Anda jarang mengubah opsi ini dan merasa terganggu, atur transparansi dan susunannya di Pengaturan — atau sembunyikan sepenuhnya lewat Tampilkan bilah menu.

🎯 Lima Mode Terjemahan

Ganti mode lewat ikon mode deteksi di bilah menu mengambang.

Kata

Arahkan ke satu kata untuk menerjemahkan kata itu saja. Bagus untuk belajar bahasa — ada pengucapan dengan ketukan (TTS).

Kalimat

Arahkan ke bagian mana pun dari kalimat untuk menerjemahkan seluruh kalimat. Mode paling populer untuk chat dan media sosial.

Paragraf

Arahkan ke blok teks untuk menerjemahkan seluruh paragraf sekaligus — ideal untuk artikel dan dokumen.

Pilih Area

Seret untuk menggambar kotak tepat di bagian yang ingin diterjemahkan. Sempurna saat tata letak ramai.

Area Tetap untuk game & subtitle

Sematkan satu area layar — aplikasi menerjemahkannya ulang secara otomatis setiap kali isinya berubah. Dibuat untuk dialog game dan subtitle video.

🌐 Bahasa

Lebih dari 110 bahasa. Bahasa sumber terdeteksi otomatis; pilih bahasa tujuan dari bilah menu. Ganti kapan saja.

Teks di layar dibaca langsung di ponsel Anda. Aksara yang didukung: Latin (Inggris, Spanyol, Prancis, Vietnam…), Tionghoa, Jepang, Korea, Dewanagari (Hindi, Marathi, Nepali…), dan — baru di versi 2.8 — aksara Arab (Arab, Persia, Urdu…), Rusia, Ukraina, Belarusia, Bulgaria, dan Thai. Bahasa dengan aksara lain, seperti Yunani, Ibrani, atau Tamil, tetap bisa dipilih sebagai bahasa tujuan, tetapi belum bisa dibaca dari layar.

🤖 Terjemahan AI (opsional)

Mesin Google bawaan gratis dan tanpa pengaturan. Lebih suka terjemahan AI? Hubungkan kunci API Anda sendiri:

  • DeepL — paket gratis tersedia di deepl.com
  • OpenAI (GPT) — kunci dari dasbor OpenAI
  • Gemini — tingkat gratis via Google AI Studio
  • Claude — kunci dari Anthropic Console

Bilah menu → mesin terjemahan → pilih mesin → tempel kunci Anda. Pemakaian ditagihkan ke akun Anda di penyedia tersebut; aplikasi tidak menambah biaya.

OpenAI, Gemini, dan Claude punya opsi tambahan di halaman kuncinya (Pengaturan → API Key). Pilih Model. Konteks ikut mengirim teks di sekitarnya (kalimat sekitar atau seluruh layar) agar kata ganti dan kata yang ambigu diterjemahkan dengan tepat. Gaya terjemahan mengatur seberapa dekat terjemahan mengikuti teks asli (harfiah, alami, atau bebas), dan Bidang menyesuaikan pilihan kata untuk teks game, komik, teknis, atau bisnis.

Jika terjemahan gagal, aplikasi menampilkan alasannya langsung di layar — kunci API tidak valid, kredit habis, batas pemakaian, atau kesalahan jaringan. Catatan: kunci yang valid saja tidak cukup — akun di penyedia juga perlu kredit atau tingkat gratis yang aktif.

🔊 Baca Nyaring & Suara TTS

Aplikasi bisa membacakan teks: ketuk ikon pengeras suara pada terjemahan, atau aktifkan baca otomatis di Pengaturan. Pengaturan Target baca memilih apakah teks asli atau terjemahan yang dibacakan.

Pilih suara di Pengaturan → Suara TTS: suara dikelompokkan per bahasa, dan mengetuk salah satunya memutar pratinjau singkat agar bisa membandingkan sebelum memilih.

💬 Membalas di Chat

Sudah menerjemahkan pesan chat? Ketuk ikon balas di kanan bawah jendela terjemahan, lalu ketik balasan dalam bahasa Anda — langsung diterjemahkan ke bahasa lawan bicara.

Ketuk salin, tempel ke chat, dan kirim. Anda bisa mengobrol panjang tanpa meninggalkan aplikasi chat.

❓ FAQ & Pemecahan Masalah

Gelembung mengambang hilang

Buka lagi aplikasinya untuk memulai ulang layanan. Jika terus terjadi, pastikan izin Tampil di atas aplikasi lain masih aktif, dan keluarkan aplikasi dari optimasi baterai (Pengaturan → Baterai → Tanpa batasan).

Terjemahan pertama lambat atau tertulis “menyiapkan”

Model pengenalan hanya diunduh sekali. Model OCR utama diunduh lewat layanan Google Play saat pertama digunakan, sedangkan model untuk teks beraksara Arab, Sirilik, dan Thai diunduh tepat setelah Anda memasang atau memperbarui aplikasi — sebelum itu, bahasa-bahasa tersebut belum bisa dibaca. Setelahnya, pengenalan bekerja offline.

Terjemahan lama saat memakai Auto

Jika bahasa sumber diatur ke Auto, aplikasi terlebih dahulu memeriksa pengenal teks mana yang cocok dengan layar, sehingga butuh waktu sedikit lebih lama — terutama untuk teks beraksara Arab, Sirilik, dan Thai. Jika Anda lebih sering membaca satu bahasa, pilih bahasa itu sebagai bahasa sumber di bilah menu agar hasilnya lebih cepat.

Tidak terjadi apa-apa di layar tertentu

Aplikasi yang memblokir tangkapan layar (aplikasi bank, pemutar video DRM) tidak bisa ditangkap — Android menyembunyikan kontennya dari semua aplikasi perekam.

Kenapa ada iklan?

Satu iklan singkat per sesi membuat semua fitur inti tetap gratis. Setelah iklan, aplikasi sepenuhnya bebas iklan sampai Anda menutupnya.

Muncul pesan ⚠ bahwa terjemahan gagal

Pesannya memberi tahu alasannya. Kunci API tidak valid: periksa lagi kuncinya di Pengaturan. Kredit habis: isi ulang di konsol penyedia — kunci valid tetap butuh kredit. Batas pemakaian: tunggu sebentar lalu coba lagi. Kesalahan jaringan: periksa koneksi Anda.

Kualitas terjemahan terasa aneh

Coba mode Kalimat atau Paragraf (konteks lebih banyak = terjemahan lebih baik), atau hubungkan mesin AI (DeepL/GPT/Gemini/Claude) untuk kualitas terbaik.

Bagaimana cara melihat tips di layar lagi?

Buka Pengaturan lalu ketuk Cara penggunaan. Selain membuka panduan ini, langkah itu juga mereset tips sehingga tips muncul lagi saat Anda memakai aplikasi.
