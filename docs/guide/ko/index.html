화면 번역 사용법

게임, 채팅, 만화, 앱 — 화면의 모든 텍스트를 실시간으로 번역하세요.

🚀 빠른 시작

1
두 가지 권한을 허용하세요. 첫 실행 시 다른 앱 위에 표시(플로팅 버블용)와 화면 캡처(화면 텍스트 인식용) 권한을 요청합니다. Android 14 이상에서는 “전체 화면”을 선택하세요.
2
짧은 광고 한 편을 시청하세요. 보상형 광고 한 편이면 앱을 닫을 때까지 광고 없이 사용할 수 있습니다. 광고를 건너뛰면 다음 번역 때 광고 화면이 다시 열립니다.
3
포인터를 텍스트 위로 끌어다 놓으세요. 화면에 플로팅 버블이 나타납니다. 버블을 끌면 포인터가 손가락을 따라옵니다. 텍스트 위에 멈춰 있으면 글자를 읽는 동안 포인터 안에서 작은 원이 돌고, 곧 그 자리에 번역이 나타납니다. 손을 떼도 몇 초간 화면에 남아 있습니다.

📌 플로팅 메뉴바

메뉴바는 화면에 항상 떠 있는 앱의 컨트롤 센터입니다. 핸들을 눌러 캡처하는 동안과 번역창이 보여지는 동안에만 잠시 숨겨집니다. 생각보다 많은 일을 할 수 있어요:

  • 감지 모드 아이콘(왼쪽) — 단어 / 문장 / 문단 / 영역 선택 / 고정 영역 모드를 전환합니다.
  • 원문 언어 — Auto가 자동으로 감지해 주며, 탭하면 특정 언어로 고정할 수도 있습니다. 아직 화면 글자를 읽을 수 없는 언어는 회색으로 표시됩니다.
  • ⇄ 스왑 — 원문·번역 언어를 한 번에 맞바꿉니다.
  • 번역 언어 — 탭해서 110개 이상의 언어 중에서 고릅니다.
  • 엔진 아이콘(오른쪽) — 탭할 때마다 번역 엔진이 전환됩니다: Google, DeepL, GPT, Gemini, Claude.

메뉴바는 화면 어디로든 드래그할 수 있습니다. 설정을 자주 바꾸지 않아 메뉴바가 거슬린다면, 설정에서 투명도와 구성을 조절하거나 메뉴바 보이기를 꺼서 아예 숨길 수 있습니다.

🎯 다섯 가지 번역 모드

플로팅 메뉴바의 감지 모드 아이콘으로 모드를 전환하세요.

단어

단어 하나를 가리키면 그 단어만 번역합니다. 어학 학습에 좋고, 탭하면 발음(TTS)도 들을 수 있습니다.

문장

문장 아무 곳이나 가리키면 문장 전체를 번역합니다. 채팅과 SNS에서 가장 많이 쓰는 모드입니다.

문단

텍스트 덩어리를 가리키면 문단 전체를 한 번에 번역합니다. 기사나 문서에 적합합니다.

영역 선택

원하는 부분만 상자로 그려서 번역합니다. 화면 구성이 복잡할 때 좋습니다.

고정 영역 게임·자막용

화면의 한 영역을 고정하면 내용이 바뀔 때마다 자동으로 다시 번역합니다. 게임 대사와 영상 자막을 위해 만들었습니다.

🌐 지원 언어

110개 이상의 언어를 지원합니다. 원문 언어는 자동으로 감지되며, 번역될 언어만 메뉴바에서 고르면 됩니다. 언제든 바꿀 수 있습니다.

화면의 글자는 휴대폰 안에서 바로 읽습니다. 지원하는 문자는 라틴 문자(영어·스페인어·프랑스어·베트남어 등), 중국어, 일본어, 한국어, 데바나가리 문자(힌디어·마라티어·네팔어 등)이며, 2.8 버전부터 아랍 문자(아랍어·페르시아어·우르두어 등), 러시아어·우크라이나어·벨라루스어·불가리아어, 태국어가 추가되었습니다. 그리스어·히브리어·타밀어처럼 다른 문자를 쓰는 언어는 번역될 언어로는 고를 수 있지만, 아직 화면에서 읽지는 못합니다.

🤖 AI 번역 (선택)

기본 Google 엔진은 무료이며 설정이 필요 없습니다. AI 번역을 쓰고 싶다면 본인의 API 키를 연결하세요:

  • DeepL — deepl.com 에서 무료 플랜 제공
  • OpenAI (GPT) — OpenAI 대시보드에서 키 발급
  • Gemini — Google AI Studio 에서 무료 등급 제공
  • Claude — Anthropic Console 에서 키 발급

메뉴바 → 번역 엔진 → 엔진 선택 → 키 붙여넣기. 사용량은 해당 서비스의 본인 계정으로 청구되며, 앱은 수수료를 받지 않습니다.

OpenAI·Gemini·Claude는 각 키 화면(설정 → API Key)에 추가 옵션이 있습니다. 모델을 고를 수 있고, 문맥은 주변 글(주변 문장 또는 화면 전체)을 함께 보내 대명사나 애매한 단어를 바르게 옮기게 합니다. 번역 스타일은 원문을 얼마나 따를지(직역·자연스럽게·의역), 분야는 게임·만화·기술·비즈니스 글에 맞는 표현을 정합니다.

번역이 실패하면 이유가 화면에 바로 표시됩니다 — 잘못된 API 키, 크레딧 부족, 사용량 한도, 네트워크 오류. 참고: 키가 유효해도 그것만으로는 부족합니다 — 해당 서비스 계정에 크레딧(또는 활성화된 무료 등급)이 있어야 합니다.

🔊 읽어주기 & TTS 목소리

앱이 텍스트를 소리 내어 읽어줍니다. 번역창의 스피커 아이콘을 탭하거나, 설정에서 번역 자동 읽기를 켜세요. 읽기 대상 설정으로 원문을 읽을지 번역문을 읽을지 고를 수 있습니다.

설정 → TTS 목소리에서 목소리를 고르세요. 목소리는 언어별로 묶여 있고, 항목을 탭하면 짧은 미리듣기가 재생되어 비교하며 고를 수 있습니다.

💬 채팅에서 답장하기

채팅 메시지를 번역했다면, 번역창 오른쪽 아래의 답장 아이콘을 눌러 보세요. 내 언어로 답장을 입력하면 상대방의 언어로 바로 번역됩니다.

복사를 누른 뒤 채팅에 붙여넣어 보내면 끝. 채팅 앱을 벗어나지 않고도 대화를 이어갈 수 있습니다.

❓ 자주 묻는 질문 & 문제 해결

플로팅 버블이 사라졌어요

앱을 다시 열어 서비스를 재시작하세요. 반복된다면 다른 앱 위에 표시 권한이 유지되어 있는지 확인하고, 배터리 최적화에서 앱을 제외하세요 (설정 → 배터리 → 제한 없음).

첫 번역이 느리거나 “준비 중”이라고 나와요

인식 모델은 한 번만 내려받습니다. 기본 OCR 모델은 처음 사용할 때 Google Play 서비스를 통해 받고, 아랍 문자·키릴 문자·태국어용 모델은 앱을 설치하거나 업데이트한 직후에 받습니다. 받기 전까지는 해당 언어를 읽지 못합니다. 이후에는 인식이 오프라인에서도 작동합니다.

Auto로 두면 번역이 오래 걸려요

원문 언어가 Auto이면 먼저 화면에 맞는 문자 인식기를 고르느라 시간이 조금 더 걸립니다. 아랍 문자·키릴 문자·태국어는 특히 그렇습니다. 주로 한 언어를 읽는다면 메뉴바에서 그 언어를 원문 언어로 지정하면 더 빨라집니다.

일부 화면에서는 아무 일도 일어나지 않아요

스크린샷을 차단하는 앱(은행 앱, DRM 영상 플레이어)은 캡처할 수 없습니다 — Android가 모든 캡처 앱으로부터 해당 콘텐츠를 숨깁니다.

왜 광고가 나오나요?

세션당 짧은 광고 한 편으로 모든 핵심 기능이 무료로 유지됩니다. 광고를 본 뒤에는 앱을 닫을 때까지 광고가 전혀 나오지 않습니다.

⚠ 표시와 함께 번역이 실패했다고 나와요

메시지가 이유를 알려줍니다. API 키 오류: 설정에서 키를 다시 확인하세요. 크레딧 부족: 해당 서비스 콘솔에서 충전하세요 — 키가 유효해도 크레딧은 별도로 필요합니다. 사용량 한도: 잠시 후 다시 시도하세요. 네트워크 오류: 연결 상태를 확인하세요.

번역 품질이 이상해요

문장·문단 모드를 써 보세요(문맥이 많을수록 번역이 좋아집니다). 최고 품질을 원하면 AI 엔진(DeepL/GPT/Gemini/Claude)을 연결하세요.

화면 안내를 다시 보고 싶어요

설정에서 사용법 안내를 누르세요. 이 안내 페이지가 열리면서 화면 안내도 초기화되어, 앱을 쓰는 동안 다시 나타납니다.
