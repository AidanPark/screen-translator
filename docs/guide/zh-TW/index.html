Screen Translate 使用指南

遊戲、聊天、漫畫、應用程式 — 即時翻譯螢幕上的任何文字。

🚀 快速上手

1
授予兩項權限。首次啟動時，應用程式會要求顯示在其他應用程式上層（用於懸浮氣泡）和螢幕擷取（用於辨識螢幕文字）。Android 14 以上請選擇「整個螢幕」。
2
觀看一則短廣告。看完一則獎勵廣告後，直到關閉應用程式前都不會再出現廣告。若跳過廣告，下次翻譯時廣告頁面會重新開啟。
3
把指標拖曳到文字上。螢幕上會出現懸浮氣泡。拖曳它，指標會跟著手指移動。在任意文字上停住：辨識文字時，指標內會有一個小圓環在轉動，接著譯文就在原處彈出。放開手指後，譯文會在螢幕上停留幾秒。

📌 懸浮選單列

選單列始終懸浮在螢幕上，是應用程式的控制中心。只有在按住指標擷取畫面時和譯文視窗顯示期間才會暫時隱藏。功能比想像中多：

  • 辨識模式圖示（左側）— 在單字／句子／段落／框選區域／固定區域之間切換。
  • 來源語言 — Auto 自動偵測；點一下也可固定為特定語言。目前還無法辨識螢幕文字的語言會顯示為灰色。
  • ⇄ 互換 — 一鍵對調來源與目標語言。
  • 目標語言 — 點一下後從 110 多種語言中選擇。
  • 引擎圖示（右側）— 每點一次切換一個翻譯引擎：Google、DeepL、GPT、Gemini、Claude。

選單列可拖曳到螢幕任何位置。如果你很少更改這些選項、覺得礙事，可在設定中調整透明度與配置，或關閉顯示選單列將其完全隱藏。

🎯 五種翻譯模式

透過懸浮選單列上的辨識模式圖示切換模式。

單字

指向一個單字，只翻譯這個字。非常適合語言學習 — 點一下還能聽發音（TTS）。

句子

指向句子中任一位置，翻譯整句。聊天和社群媒體最常用的模式。

段落

指向一段文字，一次翻譯整個段落 — 適合文章與文件。

框選區域

拖曳畫框，精確圈出想翻譯的內容。版面複雜時特別好用。

固定區域 適合遊戲與字幕

固定螢幕上的一塊區域，內容一變就自動重新翻譯。專為遊戲對白與影片字幕設計。

🌐 支援語言

支援 110 多種語言。來源語言自動偵測，只需在選單列選擇目標語言，隨時可切換。

螢幕文字直接在手機上辨識。支援的文字：拉丁字母（英文、西班牙文、法文、越南文等）、中文、日文、韓文、天城文（印地文、馬拉地文、尼泊爾文等），以及 2.8 版新增的阿拉伯字母（阿拉伯文、波斯文、烏都文等）、俄文、烏克蘭文、白俄羅斯文、保加利亞文和泰文。使用其他文字的語言，例如希臘文、希伯來文或坦米爾文，仍可選為目標語言，但目前還無法從螢幕上辨識。

🤖 AI 翻譯（選用）

內建的 Google 引擎免費且無需設定。想用 AI 翻譯？連接你自己的 API 金鑰：

  • DeepL — deepl.com 提供免費方案
  • OpenAI (GPT) — 在 OpenAI 控制台取得金鑰
  • Gemini — 透過 Google AI Studio 取得免費額度
  • Claude — 在 Anthropic Console 取得金鑰

選單列 → 翻譯引擎 → 選擇引擎 → 貼上金鑰。用量計入你在該服務商的個人帳戶，應用程式不加價。

OpenAI、Gemini 和 Claude 的金鑰頁面（設定 → API Key）還有更多選項。可以選擇模型；上下文會一併傳送周圍的文字（鄰近句子或整個螢幕），讓代名詞和語意模糊的詞翻得更準確；翻譯風格決定貼近原文的程度（直譯、自然或意譯）；領域則針對遊戲、漫畫、技術或商務文字調整用語。

翻譯失敗時，原因會直接顯示在螢幕上 — API 金鑰無效、額度不足、達到用量上限或網路錯誤。注意：僅有有效金鑰還不夠，服務商帳戶還需要有額度或可用的免費方案。

🔊 朗讀 & TTS 語音

應用程式可以朗讀文字：點一下譯文上的喇叭圖示，或在設定中開啟自動朗讀。透過朗讀對象設定選擇朗讀原文或譯文。

在設定 → TTS 語音中挑選語音：語音依語言分組，點一下即播放短預覽，方便比較後再選擇。

💬 在聊天中回覆

翻譯了聊天訊息後，點一下譯文視窗右下角的回覆圖示，用你自己的語言輸入回覆，立即翻譯成對方的語言。

點一下複製，貼到聊天中送出即可。不用離開聊天應用程式，就能完整地進行對話。

❓ 常見問題與疑難排解

懸浮氣泡不見了

重新開啟應用程式即可重新啟動服務。若經常發生，請確認顯示在其他應用程式上層權限仍開啟，並將應用程式從電池最佳化中排除（設定 → 電池 → 不受限制）。

第一次翻譯很慢或顯示「準備中」

辨識模型只需下載一次。主要的 OCR 模型在首次使用時透過 Google Play 服務下載；阿拉伯字母、西里爾字母和泰文的模型會在安裝或更新應用程式後立即下載，下載完成前無法辨識這些語言。之後，辨識可離線運作。

來源語言設為 Auto 時翻譯較慢

來源語言為 Auto 時，應用程式會先判斷哪種文字辨識模型適合目前的畫面，因此會多花一點時間，阿拉伯字母、西里爾字母和泰文尤其如此。如果你主要閱讀一種語言，在選單列中將它設為來源語言，速度會更快。

某些畫面上沒有任何反應

禁止截圖的應用程式（銀行應用程式、DRM 影片播放器）無法被擷取 — Android 會對所有擷取類應用程式隱藏其內容。

為什麼會看到廣告？

每次工作階段只需看一則短廣告，即可免費使用全部核心功能。看完廣告後，直到關閉應用程式前完全無廣告。

出現 ⚠ 提示說翻譯失敗

提示會告訴你原因。API 金鑰無效：在設定中重新檢查金鑰。額度不足：到服務商控制台儲值 — 金鑰有效仍需額度。用量上限：稍候再試。網路錯誤：檢查網路連線。

翻譯品質怪怪的

試試句子或段落模式（上下文越多，翻譯越好），或連接 AI 引擎（DeepL/GPT/Gemini/Claude）獲得最佳品質。

如何再次查看畫面提示？

開啟設定，點一下使用方式。除了開啟本指南，它還會重設提示，讓提示在你使用應用程式時再次出現。
